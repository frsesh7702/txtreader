# 朗读女 ReaderTTS

基于百度智能云语音合成 API 的 TXT 朗读软件。PyQt5 界面 + pygame 音频播放。

## 功能

- **朗读 TXT** — 分句高亮跟随（当前句高亮），暂停即时静音
- **朗读列表** — 右侧悬浮栏管理多个文件，双击载入
- **22 种百度发音人** — 基础/精品/臻品三档音库（度小美、度逍遥、度小鹿、度灵儿等）
- **智能分句** — 一个合成段 = 一个句子，高亮精确，朗读连贯
- **伴音 BGM** — 最多 5 首备用音乐一键切换，音量实时可调
- **阅读区外观自定义** — 字体大小、文字颜色、文档背景色、朗读句背景色、段落间距
- **背景图** — png/jpg/webp 可选，透明度 0~100%，铺满阅读区
- **生成声音文件** — 全文导出为单个 MP3
- **逐遍循环** — 1~99 遍

## 快速开始

### 方式一：直接运行（需要 Python 3.8+）

双击 `启动朗读女.bat` 即可。

首次运行会自动 pip 安装依赖：

```
pip install PyQt5 pygame requests
```

### 方式二：打包好的 EXE

GitHub → [dist/ReaderTTS.exe](https://github.com/frsesh7702/txtreader/blob/main/dist/ReaderTTS.exe)（70MB，单文件，无控制台窗口，免安装）

### 方式三：开发运行

```powershell
py -3 main.py
```

## 配置 API Key（必读）

软件启动后需要配置百度语音合成 API Key 才能朗读。

1. 打开 [百度智能云语音控制台](https://console.bce.baidu.com/ai/#/ai/speech/overview/index)
2. 创建应用 → 勾选语音合成 → 记下 **API Key** 和 **Secret Key**
3. 免费领取**基础音库、精品音库、臻品音库**三个档次的额度（分别领取，否则用臻品音色会 503 报错）
4. 软件菜单 → **选项 → 百度语音设置** → 填入 Key → 测试连接

> 没有 Key 只能打开界面和编辑文本，**无法朗读**。

| F7 | 上一句 |
| F8 | 下一句 |

### 设置菜单

菜单栏 **设置 → 伴音与背景设置**：

- 伴音组：启用开关、+ 添加音乐（最多 5 首备用）、− 删除、清空、伴音音量
- 背景组：选择图片、清除、透明度 0~100%
- 外观组：字体大小、字体颜色、朗读句背景色、文档背景色、段落间距

### 悬浮朗读列表

主界面上 **📋 朗读列表** 按钮 → 弹出/收起右侧栏：

- **+ 添加** — 选择 txt，支持多选
- **− 删除** / **清空** — 管理列表
- **双击** 某一项 → 载入到阅读区
- **关闭按钮** 只是隐藏窗口，列表不丢

## 常见问题

**Q: 点播放没声音？**
A: 首次使用请先在「选项 → 百度语音设置」填入 API Key / Secret Key，并点「测试连接」确认。

**Q: 播放时提示 503 / 额度不足？**
A: 该发音人所在音库（基础/精品/臻品）的免费额度未领取。到百度语音控制台 → 语音合成 → 分别领取三个档次的免费额度后再试。

**Q: 伴音不加载？**
A: pygame 支持 mp3 / wav / ogg，flac 等格式不认。伴音要处于「启用」勾选状态且选中了列表中的某一首。

**Q: 段落还是太松？**
A: 设置 → 外观 → 段落间距，拉到 **-10 ~ -20 px** 压缩空行高度。

**Q: EXE 杀毒软件报病毒？**
A: PyInstaller 打包的单文件 EXE 会被某些杀软误报，属于已知现象。可以加信任或改用 bat + Python 直接运行。

**Q: EXE 体积为什么 70MB？**
A: 打包了完整 PyQt5 + pygame + SDL，纯 GUI 体积就约 50MB，属于正常范围。

## 项目结构

```
reader/
├── main.py                入口
├── main_window.py         主界面 + 阅读区（带背景图合成）
├── baidu_tts.py           百度语音合成 API（token 自动刷新、分句）
├── player.py              pygame 播放控制器（分句预取、暂停/继续/跳段）
├── prefs_dialog.py        设置对话框（伴音/背景/外观）
├── settings_dialog.py     百度 API Key 设置对话框
├── config.py              配置读写（config.json）
├── 启动朗读女.bat         一键启动（pythonw 无窗口）
└── dist/ReaderTTS.exe     打包产物
```

## 重新打包 EXE

```powershell
py -3 -m pip install --upgrade pyinstaller
py -3 -m PyInstaller --noconsole --onefile --name ReaderTTS ^
    --hidden-import=pygame.mixer ^
    --hidden-import=pygame.midi ^
    --hidden-import=pygame.ftfont ^
    --collect-all=PyQt5 main.py
```

产物：`dist/ReaderTTS.exe`
